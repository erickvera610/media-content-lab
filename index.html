What the results mean

All audience labels are synthetic. Views, likes, comments and shares are excluded from the prediction features because those outcomes are unknown before publication. Coefficients describe this simulation, not causal audience behavior.

Read the case study for measured Python results, methodology and remaining limitations. JavaScript uses a different seeded random generator, so synthetic metrics may differ.
